# Food Delivery Analytics

## About the Project
This project analyzes food delivery data to understand the factors affecting delivery time and performance.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- SQL (upcoming)

## Work Completed
- Data cleaning using Pandas
- Exploratory Data Analysis (EDA)
- Created 4 charts to analyze delivery performance

## Objective
To identify factors affecting delivery time and suggest ways to improve delivery efficiency and customer satisfaction.

## Future Work
- SQL business analysis
- Business insights and recommendations
